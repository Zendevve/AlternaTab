# Plan: 07-01: Production Release Prep

**Status**: Planned
**Depends On**: None
**Requirements**: FR-004, FR-006, NFR-001, NFR-003

## Objective

Deliver a highly optimized, fully minified, source-map-free, and console-log-stripped production build of alternaTab, validated against Manifest V3 compliance audits, and packaged into a release-ready zip file for Chrome Web Store distribution.

## Steps

1. **Vite Production Optimization**:
   - Update `vite.config.ts` to disable sourcemaps (`sourcemap: false`).
   - Configure `esbuild` minifier in `vite.config.ts` to automatically strip `console` statements and `debugger` calls (`esbuild: { drop: ["console", "debugger"] }`).

2. **Add Native Packaging Script**:
   - Add a `package` script to `package.json` that compiles the build and uses Windows PowerShell's native `Compress-Archive` utility to bundle the `dist/` outputs into a clean `release/alternatab-v1.0.0.zip` file.

3. **Production Compilation & Package**:
   - Execute `npm run package` to run the production compiler and build the release zip archive.

4. **Verify Release Quality**:
   - Inspect the compiled `dist/` assets to ensure:
     - No `.map` files are produced.
     - All JavaScript files are minified.
     - `console.log` messages have been successfully stripped.
   - Assert the `release/alternatab-v1.0.0.zip` archive has been generated and populated correctly.

## Verification

### Automated Verification
Run a verification script that checks:
- The `release/alternatab-v1.0.0.zip` file exists and has size > 0.
- No files ending in `.map` exist in `dist/`.
- No `console.log` invocations exist in `dist/src/content/index.js` or `dist/src/background/index.js`.
