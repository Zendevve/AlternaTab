  <action>
    Define TabInfo and TabAdapter interfaces in src/shared/adapter.ts:
    ```typescript
    export interface TabInfo {
      id: number;
      windowId: number;
      title: string;
      url: string;
      favIconUrl?: string;
      incognito: boolean;
    }

    export interface TabAdapter {
      getActiveTab(): Promise<TabInfo | null>;
      getRecentTabs(limit: number): Promise<TabInfo[]>;
      switchToTab(tabId: number, windowId: number): Promise<void>;
      onTabActivated(callback: (tabId: number, windowId: number) => void): void;
      onTabRemoved(callback: (tabId: number) => void): void;
      onTabCreated(callback: (tab: TabInfo) => void): void;
    }
    ```
    
    Implement ChromeTabAdapter:
    - Uses `chrome.tabs.query({ active: true, currentWindow: true })` for `getActiveTab`.
    - Uses `chrome.tabs.query({})` for `getRecentTabs` (returns open tabs in standard window order, to be sorted by tracker).
    - Uses `chrome.tabs.update(tabId, { active: true })` and `chrome.windows.update(windowId, { focused: true })` for cross-window switching.
    - Wire up chrome listener callbacks for `onActivated`, `onRemoved`, `onCreated`.
    
    Implement MockTabAdapter:
    - Retains an in-memory array of mock `TabInfo` entries.
    - Tracks active selection state.
    - Emulates `switchToTab` by updating active states.
    - Allows adding/removing tabs programmatically in tests.
    - Registers callbacks in lists and exports triggers (e.g. `triggerActivation(tabId, windowId)`) for test cases.
    
    Write unit tests in src/shared/__tests__/adapter.test.ts confirming that MockTabAdapter additions, active tracking, switching focus, and event triggers behave as expected under Vitest.
  </action>
