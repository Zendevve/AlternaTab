# Phase 6 Plan: Automated Testing & Performance QA

**Configure Playwright E2E browser tests, verify core flows, assert render speed benchmarks, and confirm Vitest unit test coverage exceeds >90%.**

## Tasks

### Task 1: Document & Audit Existing Vitest Unit/Integration Tests
- **Objective:** Verify existing 45 tests cover StorageManager, MRUTracker, KeyHandler, Options, Onboarding, and Background scripts.
- **Verification:** Run `npm run test` and check output.

### Task 2: Setup Playwright Configuration & Dependencies
- **Objective:** Install `@playwright/test` and configure `playwright.config.ts` to launch Chromium with the unpacked extension.
- **Files:** `playwright.config.ts`, `package.json`

### Task 3: Create E2E Test Fixtures
- **Objective:** Create a unified test fixture file `e2e/fixtures.ts` to dynamically resolve the loaded extension ID and handle Chromium page boots.
- **Files:** `e2e/fixtures.ts`

### Task 4: Implement Extension E2E Flow Specs
- **Objective:** Write E2E specifications for options configuration, onboarding steps, and extension popups.
- **Files:** `e2e/onboarding.spec.ts`, `e2e/options.spec.ts`, `e2e/popup.spec.ts`

### Task 5: Implement Switcher Overlay Injection & Performance Benchmark Test
- **Objective:** Verify switcher overlay injection and measure render/load speeds inside a real page context to assert <16ms latency.
- **Files:** `e2e/switcher.spec.ts`

## UAT Criteria

1. **Successful Extension Boot:** Playwright loads the built extension (`dist`) successfully without any runtime console crashes.
2. **Onboarding E2E Flow:** Onboarding wizard loads and allows stepping through to Step 3.
3. **Options E2E Sync:** Modifying Options fields in the E2E browser saves preferences instantly.
4. **Performance Benchmark Verification:** Switcher overlay loads and renders mock tabs inside Chromium page in <50ms, asserting peak responsiveness.
