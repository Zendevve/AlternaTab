# alternaTab

**Alt+Tab for the Browser** — a Chrome extension that brings OS-style window switching to browser tabs.

Press **Alt+Q** to open a floating overlay of your most recently used tabs, cycle through them, and switch instantly — all from the keyboard.

## Features

- **Keyboard-driven tab switching** — open overlay with Alt+Q, cycle with Alt+Q (forward) or Alt+Shift+Q (reverse), confirm with Enter/Space
- **Hold mode (default)** — hold Alt, release to switch, or dismiss with Esc
- **Toggle mode** — overlay stays open until you select or dismiss
- **MRU (Most Recently Used) tracking** — tabs ordered by recency, across windows, with incognito isolation
- **Customizable** — max visible tabs (3–15), theme (auto/light/dark), layout (grid/list), window badges
- **Privacy-first** — 100% local, no network requests, no analytics
- **Glassmorphism UI** — premium frosted-glass design that adapts to system theme

## Quick Start

1. Install from the [Chrome Web Store](#) (link TBD)
2. Press **Alt+Q** on any page
3. Keep **Alt** held, press **Q** to cycle tabs
4. Release **Alt** to switch
